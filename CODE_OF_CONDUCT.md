# Code of conduct

This project adopts the **[Contributor Covenant, version 2.1][covenant]** in full as
its code of conduct. The canonical text is at that link; it is referenced rather than
copied so it cannot drift from the original.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Where it applies

The issue tracker, security advisories, and any other space where someone is acting on
behalf of this project in public. Pull requests are closed automatically
(see [CONTRIBUTING.md](CONTRIBUTING.md)), so in practice this means the issue tracker.

## Reporting

Report unacceptable behavior **privately to the repository maintainers through
GitHub** — contact the repository owner directly, or use GitHub's own abuse reporting
if the behavior violates GitHub's terms as well.

There is deliberately no e-mail address here: this repository pins no
organization-specific contact value, for the same reason described in
[SECURITY.md](SECURITY.md).

All reports are reviewed privately. Maintainers are obliged to respect the privacy and
security of anyone who reports an incident.

## Enforcement

Maintainers may edit, hide, or delete comments, issues, and other contributions that
are not aligned with this code of conduct, and may temporarily or permanently ban any
contributor for behavior they consider inappropriate, threatening, offensive, or
harmful. The Contributor Covenant's enforcement guidelines — correction, warning,
temporary ban, permanent ban — are the escalation ladder.
